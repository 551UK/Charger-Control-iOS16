# USB Charge Control

USB Charge Control lets you set a maximum wired USB charging current on supported jailbroken iPhones (iOS 16, Dopamine rootless). It displays charging information and lets you restore normal charging whenever you want.

## Features

- **Adjustable current cap** — Choose a USB charging-current ceiling from 500 to 2400 mA in 100 mA steps.
- **Live charging data** — View charger rating, input-rail and battery power/current, USB voltage, and the effective USB current limit.
- **Charging status** — See when a charger connects or disconnects and when a current cap is applied.
- **One-tap restore** — Remove your selected cap and return to normal charging.
- **Background watchdog** — Helps manage charging limits as charging conditions change.

**Note:** A cap limits current; it does not force faster charging. iOS telemetry can take 15–20 seconds to update the displayed readings and current cap.
