# USB Charge Control v0.8.10

Minor visual update to v0.8.9 for rootless iOS 16.

- Home-screen icon label shortened to **Charge Control** (the executable, package name and bundle ID remain unchanged).
- Slightly tighter spacing in the **Charging Data** section.
- Removed the battery percentage from that section; displays **Charging: Yes | USB Voltage: 5.00 V** (illustrative value) on one line instead of two.

All charging cap, daemon, telemetry, Restore and watchdog functionality is unchanged. Existing header, slider markers, blue title and GitHub footer are preserved.

Install over v0.8.9 in Sileo; respring if the old home-screen label remains cached.
