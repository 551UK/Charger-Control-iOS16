# USB Charge Control v0.8.9

**Layout-only update** for the native rootless iOS 16 USB charging controller.

- Centered **USB Charge Control** title.
- Removed the `551UK • Dopamine rootless • iOS 16` subtitle.
- Moved the blue **CHARGING CURRENT CAP** heading and selected mA value onto one row.
- Fixed the **2400mA** marker at the right end of the slider.
- Added a permanent tappable GitHub repository link at the bottom.
- Renamed the Sileo package and app to **USB Charge Control**, with a concise description.

**Preserved:** current-cap control, Restore behaviour, iOS telemetry-delay notice, watchdog, charger/battery readings and v0.8.8 one-app-only packaging.

Install the DEB with Sileo directly over v0.8.8. The native executable has been recompiled for the layout changes; iPhone testing is still needed.
